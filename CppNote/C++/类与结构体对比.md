C++ 中 `class` 与 `struct` 几乎相同，**唯一区别是默认访问权限**

- `struct` 默认 `public`
- `class` 默认 `private`

```cpp
struct S {
    int x;          // 默认 public
};
class C {
    int x;          // 默认 private
public:
    C() : x(0) {}
};

S s;  s.x = 1;      // OK
C c;  // c.x = 1;   // 错误：x 是 private
```

- 约定俗成：`struct` 用于“纯数据包 / POD”，`class` 用于需要封装（成员私有）的类型
- 两者都能有构造函数、成员函数、继承、模板——能力完全一致
