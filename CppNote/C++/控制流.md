控制流决定代码执行的顺序（对应视频第 12/14/15 集：条件分支、循环、控制流语句）。

```cpp
// 条件与分支
int score = 85;
if (score >= 90)        std::cout << "A";
else if (score >= 60)   std::cout << "Pass";
else                    std::cout << "Fail";

// switch：适合离散的整数 / 枚举值
int day = 1;
switch (day) {
    case 1: std::cout << "Mon"; break;   // break 防止贯穿（fall-through）
    default: std::cout << "?";
}

// 循环
for (int i = 0; i < 5; ++i)  std::cout << i;   // 0..4
int j = 0;
while (j < 5) { std::cout << j++; }            // 先判断后执行
do { std::cout << j--; } while (j > 0);        // 先执行后判断

// 控制语句
break;          // 跳出当前循环 / switch
continue;       // 跳过本次循环剩余部分，进入下一轮
return;         // 退出函数
```

- `if/else` 判断布尔表达式；C++ 中 `0`、空指针、`false` 视为假，其余为真
- 忘记 `break` 会让 switch 贯穿到下一个 case（有时故意为之）
- 变量定义见 [[C++变量]]；函数体内使用见 [[C++函数]]
