C++ 函数只有一个返回类型，但有多种方式“返回多个值”（对应视频第 52 集）。

```cpp
#include <tuple>
#include <string>

// 方式1：用结构体打包（最清晰，成员有名字）
struct Result { int sum; int product; };
Result Compute(int a, int b) { return {a + b, a * b}; }

// 方式2：std::pair / std::tuple（适合临时组合）
std::tuple<int, std::string> Get() { return {42, "ok"}; }

int main() {
    auto [s, p] = Compute(2, 3);     // C++17 结构化绑定
    auto [num, msg] = Get();
    // 旧写法：std::tie(s, p) = Compute(2, 3);
}
```

- 首选**结构体**，成员命名让调用方一目了然
- `std::pair` 适合两个值，`std::tuple` 适合更多；C++17 结构化绑定 `auto [a,b]` 最简洁
- 也可用输出参数（引用 / 指针）带回结果
