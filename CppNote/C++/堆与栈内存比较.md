程序运行时内存主要分为**栈（stack）**和**堆（heap）**两块（对应视频第 54 集）。

```cpp
void f() {
    int a = 5;                  // 栈：函数结束自动销毁，快
    int* p = new int(5);        // 堆：需手动 delete，慢但生命周期可控
    delete p;
}
```

| 维度 | 栈 stack | 堆 heap |
|---|---|---|
| 分配速度 | 极快（移动栈指针） | 较慢（需找空闲块） |
| 生命周期 | 作用域结束自动释放 | 手动 `delete` / `delete[]` 或智能指针 |
| 大小限制 | 较小（易栈溢出） | 大（受系统内存限制） |
| 碎片 | 无 | 可能产生碎片 |

- 默认用栈；需要“跨作用域存活”或“大对象 / 动态数量”才用堆
- 用堆时优先 `std::unique_ptr` / `std::shared_ptr` 管理，避免内存泄漏
- 生命周期细节见 [[对象生存期]]；动态分配见 [[new]]、[[智能指针]]、[[指针]]
