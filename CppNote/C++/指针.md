指针是“保存内存地址”的变量，通过它可间接访问 / 修改内存

```cpp
int value = 42;
int* p = &value;     // & 取地址；p 指向 value
*p = 10;             // * 解引用：改写 p 指向的内存，value 变为 10
std::cout << value;  // 输出 10

int* np = nullptr;   // 空指针，不指向任何对象（C++11 起用 nullptr 而非 NULL）
if (np) { /* np 非空才进入 */ }
```

- `int*` 表示“指向 int 的指针”，`&value` 的类型是 `int*`
- 解引用 `*` 访问目标；对空指针解引用会崩溃
- 指针算术：`p + 1` 按指向类型大小（int 为 4 字节）偏移
- 数组名在很多语境下会**退化**为指向首元素的指针
- 与 [[引用]] 对比；函数指针见 [[函数指针]]；动态分配见 [[new]]、[[智能指针]]
