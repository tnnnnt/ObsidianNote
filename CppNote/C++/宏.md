```cpp
#include <iostream>
#define out std::cout
#define LOG(x) out << x << std::endl
int main() {
	out << "Hello, World!" << std::endl;
	LOG("This is a log message.");
	return 0;
}
```

高级用法
对项目属性在Debug配置下的此处增加“DEBUG”定义，在Release配置下的此处增加“RELEASE”定义

![[Pasted image 20261024164930.png]]

```cpp
#include <iostream>
#ifdef DEBUG
#define LOG(x) std::cout << x << std::endl
#else
#define LOG(x)
#endif
int main() {
	LOG("This is a log message.");
	return 0;
}
```

此时只会在Debug下打印日志

更好的做法，不改变项目属性
```cpp
#include <iostream>

#define DEBUG 0

#if DEBUG == 1
#define LOG(x) std::cout << x << std::endl
#else
#define LOG(x)
#endif
int main() {
	LOG("This is a log message.");
	return 0;
}
```

另外，可以用#define 0加#endif注释一些代码

使用反斜杠宏定义多行代码
```cpp
#include <iostream>
#define MAIN int main() \
{\
	std::cout << "Hello, World!" << std::endl; \
}

MAIN
```
