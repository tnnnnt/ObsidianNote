字符串字面量（如 `"hello"`）是**常量字符数组**，类型 `const char[N]`，存放在只读数据段（对应视频第 33 集）。

```cpp
const char* s = "hello";   // s 指向只读内存，不要修改！
// s[0] = 'H';            // 未定义行为

// 相邻的字符串字面量会自动拼接
const char* t = "Hello, " "World!";   // == "Hello, World!"

// C++11 原始字符串：忽略转义，\ 不当转义符
const char* path = R"(C:\Users\name\file.txt)";

std::string str = "abc";   // 从字面量构造 std::string
auto len = str.length();   // std::string 是可修改、可动态增长的字符串
```

- `"..."` 末尾编译器自动补 `\0`，所以 `"hello"` 实际占 6 个字符
- `std::string` 与字面量不同：前者是对象（可改、可增长），后者是只读数组
- 用 `std::string` 而非裸 `char*` 处理文本更安全；字符串基础见 [[字符串]]
- 字面量本质是只读的，相关限定见 [[const]]；宏里常见见 [[宏]]
