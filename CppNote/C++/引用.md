引用是“已存在变量的别名”，声明时必须初始化，之后不能改指他人

```cpp
int a = 10;
int& ref = a;     // ref 是 a 的别名
ref = 20;         // 等价于 a = 20
std::cout << a;   // 输出 20

// 引用做函数参数：避免拷贝，且能修改实参
void Increment(int& x) { x++; }
int n = 1;
Increment(n);     // n 变为 2
```

- 引用本质是指针的“语法糖”，但更安全：不能为 null、不能重绑定
- 优先用引用传参 / 返回；需要“可空 / 可重指向 / 指针算术”时才用 [[指针]]
- `const T&` 常用于只读传参：既避免拷贝又保证不修改
- 函数参数见 [[C++函数]]；变量基础见 [[C++变量]]
