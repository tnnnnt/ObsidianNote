虚函数允许在子类中重写方法，常和[[多态]]配合使用
```cpp
#include <iostream>
class Entity {
public:
	virtual std::string GetName() const { return "Entity"; }
};
class Player : public Entity {
public:
	std::string GetName() const override { return "Player"; }
};
static void PrintName(const Entity& entity) {
	std::cout << entity.GetName() << std::endl;
}
int main() {
	Entity entity;
	Player player;
	PrintName(entity);
	PrintName(player);
	return 0;
}
```
将覆盖函数标记为[[override]]可以提高可读性和防止函数签名错误

使用虚函数是有代价的，会增加运行时成本（很小）：
1. 需要额外的内存来存储virtual表，这样才可以分配到正确的函数，基类也要有一个成员指针指向virtual表
2. 调用虚函数时需要遍历virtual表来确定要映射到哪个函数
