# 1. 不使用模板，从0开始改一个Rusk

创建项目
![[Pasted image 20260926131312.png]]

安装软件包后右上角打开UNITY
![[Pasted image 20260926131504.png]]

导入角色与衣服头发等素材
![[Pasted image 20260926140957.png]]

新建一个Scene场景，并建议以角色名命名，进入Scene
![[Pasted image 20260927113113.png]]

将 **Directional Light**（定向光）改为**白色**，以防色差。
![[Pasted image 20260927113211.png]]

将**角色**预制件拖入场景并解包，**位置和旋转应为 `(0, 0, 0)`**。
![[Pasted image 20260927113534.png]]

将衣服、头发等物品的**预制件**拖入角色模型内并解包，建议像如图一样分类。
![[Pasted image 20260927114700.png]]

把原版衣服头发也隐藏掉（除非是完全确定以后都不会用到，否则不要轻易删除，建议设置为EditorOnly）

添加**Gesture Manager**，不需要解包，在**Gesture Manager**中点击**Enter Play-Mode**可以测试模型
![[Pasted image 20260927133500.png]]

骨骼绑定，这里将Rusk场景拷贝一份，命名为Rusk_MA，下面分别使用两种骨骼绑定方法，Rusk场景使用古法绑骨，Rusk_MA使用MA绑骨，古法绑骨适合做绿模但不方便维护，MA绑骨不适合做绿模但方便维护
