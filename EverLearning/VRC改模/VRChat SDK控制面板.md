## 编译界面
![[Pasted image 20260911001600.png]]
1. 上传页签`按钮`。
2. 选择上传的模型（当一个场景中同时存在多个模型时使用）。
3. `名称*`：模型的昵称。
4. 模型权限（能见度）。
5. 模型类别。
6. 模型类别2。
7. 内容警告：模型可能包含的不适合的内容。
8. 标签：模型标签。
9. 介绍：模型介绍。
10. `封面*`：模型封面，封面尺寸：`1200 x 900`
11. 选择`本地图像`作为封面。
12. 从`场景中截图`作为封面。
13. 模型检查器：  
    `检查模型`是否符合VRChat官方最新的`性能与规格`相关规定。
14. 构建类型：
- `Build & Publish Your Avatar Online`：构建并上传你的模型到你的`VRChat`账号。
- `Build & Test Your Avatar`：不上传模型，仅构建模型到你的`本地`进行测试（仅支持Windows平台）。
15. 上传的平台：
- Windows：使你的模型能被`PC平台`的玩家看见。
- Android：使你的模型能被`安卓移动平台`的玩家看见。
- iOS：使你的模型能被`苹果系统`的玩家看见。
- 其中`Android`和`iOS`平台需要安装额外的`Unity模块`，对模型的性能要求极为苛刻。
16. 构建和上传模型按钮：
- 在上传之前，必须设置模型的`昵称`和`封面`。

## 管理界面
![[Pasted image 20260911002413.png]]
1. 账号内容管理页签`按钮`。
用于管理你的`VRChat账户`中已上传的所有内容，拥有最高权限。
2. 从`网页端`管理你的上传`世界`或`模型`。
多此一举的功能，既然这里就能管理还去网页做什么？
3. 刷新：刷新内容列表。
4. 搜索：从已上传的内容中搜索。
5. 角色模型列表。
6. （仅当本地存在测试模型时显示）本地测试模型列表。
7. 世界地图列表。

## 设置界面
![[Pasted image 20260915231524.png]]
1. 设置页签**按钮**。
2. 开发人员相关设置（默认设置）。

|**默认**|**标题**|**作用**|
|---|---|---|
|关闭|**Show Extra Options on Account page**|在 SDK 的 Account 页签中展开额外的功能按钮。|
|启用|**Show Help Boxes on SDK components**|在 Inspector 面板中所有 VRChat 组件下方额外显示一行提示文字，方便理解参数含义。|
|关闭|**API Logging Enabled**|将 SDK 与 VRChat 服务器之间的 HTTP 通信全部输出到 Console。调试接口或排查上传错误时打开，平时关闭以免刷屏。|
|关闭|**Override ... Detail-Preserving ... Downscaling**|启用后，所有纹理的 mipmap 会再用 Kaiser 滤波跑一次锐化算法，远距离看贴图更清晰。目前仍属实验性质，可按需打开。|
|启用|**Use conservative settings for DPID mipmapping**|上一选项的“保守模式”。官方发现激进锐化在部分贴图上会出现锯齿/噪点，于是默认勾选保守模式；若你希望更锐一点，可取消此项再做对比测试。|
|启用|**Execute VRChat Constraints in Edit Mode**|在编辑模式下实时运算，方便预览。若场景约束太多导致编辑卡顿，可关闭此项，只在 Play Mode 或上传后生效。|
|收起|**Show Local IP Address**|显示本地 IP 地址。|

3. 角色模型设置。

|**默认**|**标题**|**作用**|
|---|---|---|
|关闭|**Show All Avatar Performance Details**|显示角色模型的所有性能参数细节。|

4. VRChat 游戏客户端。
功能
- 测试**世界地图**时需要用到。
- **Edit**：编辑 **VRChat 游戏客户端**路径（指定到 `VRChat.exe`）。
- **Revert to Default**：恢复默认路径。
