## 网络环境排查
这里只展示报错内容中的**部分字段**，请自行核对排查。
上传模型时
- 不要使用可暂停时长、免费等廉价加速器。
- 不要**同时开启多个加速器**。
- 不要将**加速器**和**魔法**同时开启。
- 不要将**加速器**、**魔法**和**组网工具**同时开启。
> 常见组网工具：Radmin、Easytier、ZeroTier、Tailscale、Hamachi、蒲公英、游侠对战平台等。**如果使用过这些工具，可能需要手动关闭相应的虚拟网卡**。

## 不要在预制件界面上传
若在预制件编辑界面中上传模型，会直接失败。请先退出预制件编辑模式，再执行上传。

## Failed to load avatar data: "Missing Credentials".
- **位置**：**Console**、**VRChat SDK 控制面板**
- **含义**：缺少登录凭证。
- **原因**：通常是在上传模型前切换了**加速器**节点导致的。
- **解决方案**：开启加速器后，重新打开项目（即关闭 **Unity Editor**，再从 **Unity Hub** 打开该项目），并重新登录 **VRChat SDK 控制面板**。

## Loaded data for an avatar we do not own, clearing blueprint ID.
- **位置**：**Console**
- **含义**：这不是你的 Avatar，已清除蓝图 ID。
- **原因**：通常是网络质量差造成的；另一种原因是你使用了别人的工程文件。
- **解决方案**：更换质量好的加速器（如 UU、biubiu 等），使用 **TUN 模式**（又称路由模式/虚拟网卡模式），然后重新上传。

## Failed to upload file.
- **位置**：**Console**、**VRChat SDK 控制面板**
- **含义**：上传文件失败。
- **原因**：通常是网络质量差造成的；另一种可能是**系统环境**或**项目路径**含有中文，[点击这里](https://vrclearn.gamemode1.com/docs/start/check-system)查看。
- **解决方案**：检查**系统环境**与**项目路径**，并更换质量好的加速器（如 UU、biubiu 等），使用 **TUN 模式**（又称路由模式/虚拟网卡模式）。

## Avatar validation failed.
- **位置**：**Console**、**VRChat SDK 控制面板**
- **含义**：Avatar 安全验证不通过。
- **原因**：造成该项报错的原因很多，需要逐个排查：
1. Avatar 的参数（模型面数、同步参数、内存占用等）超出了官方上限，需要适当精简。
2. Avatar 中含有无效组件：检查衣物、道具中是否有组件显示 `Missing Script`。
3. **系统环境**或**项目路径**含有中文，[点击这里](https://vrclearn.gamemode1.com/docs/start/check-system)查看。
4. 网络/加速器质量差。

## Failed to agree to the ownership agreement.
- **位置**：**Console**、**VRChat SDK 控制面板**
- **含义**：未能达成所有权协议。
- **原因**：未弹出协议同意框，由网络质量差或 Bug 导致。
- **解决方案**：参考[本视频](https://www.bilibili.com/video/BV1HjJTzWEfx)安装 **VRChat SDK Patcher**。
